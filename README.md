# Anti-Vision ToDo

行動経済学の「損失回避(Loss Aversion)」を軸にした、ToDo・習慣トラッキングアプリ。

ビジョンボードのように「理想の未来」を描くのではなく、**このまま何も変えなかったら訪れる、避けたい未来(Anti-Vision)** を先に書き出し、それを避けるための行動を日々記録していく、という逆転の発想で作っています。

## なぜ Anti-Vision なのか

多くの習慣化アプリは「達成」「ストリーク」「バッジ」といったポジティブな強化(ゲーミフィケーション)で作られています。このアプリは逆に、行動経済学で知られる **人は何かを得る喜びより、何かを失う恐れの方を強く感じる** という性質を利用し、

- 避けたい未来を具体的な文章にして常に見える場所に置く
- タスクの「やる理由」ではなく、やった後の「実際の行動」を記録する
- 続けている実感を、カレンダーと数値でシビアに可視化する

という設計になっています。

## 主な機能

- **複数のAnti-Vision管理** — アンチビジョンごとに独立した記録・カレンダー・継続日数を持てる(タブで切り替え)
- **行動ログ** — 「何をしたか」「場所」「かかった時間」「取り組みの深さ」「振り返りコメント」を記録。時間は手動選択のほか、ストップウォッチでの実測も可能
- **カスタムカテゴリ** — 場所・タスクのカテゴリ、取り組みの深さの段階(名前・数・並び順)をすべて自由に編集可能(ドラッグ&ドロップで並び替え、マウス・タッチ両対応)
- **月間カレンダー** — 記録の有無・深さに応じて色分けされたカレンダー。前月/次月をページング
- **継続ダッシュボード** — 連続継続日数、最長記録、継続率、合計時間、平均クオリティなどを表示
- **JSONエクスポート** — 全データをJSONファイルとしてバックアップ可能

## 技術構成

- 素のHTML / CSS / JavaScript のみ(フレームワーク・ビルドツール不使用)
- 外部ライブラリなし(Google Fontsの読み込みのみ)
- データはすべてブラウザの `localStorage` に保存。サーバー通信は一切行いません

## 使い方

`anti-vision-todo.html` はダブルクリックで直接開いても一応動きますが、`file://`から開いた場合、ブラウザによって`localStorage`(データの保存先)の挙動が未定義・不安定です(MDN公式ドキュメントでも明記されています)。ブラウザや保存場所を変えるとデータが消えることがあるため、以下のいずれかを推奨します。

- **簡易ローカルサーバーを立てる**(このフォルダで実行)
  ```
  python3 -m http.server
  ```
  その後 `http://localhost:8000/anti-vision-todo.html` を開く
- **VSCodeの「Live Server」拡張機能**で開く

## データの保存の仕組み

すべてのデータはブラウザの**localStorage**という機能に保存されます。サーバーやデータベースは一切使っていません。

- **形式**: アプリ内のデータ(アンチビジョン・行動ログ・カテゴリなど)をまとめた1つのオブジェクトを、`JSON.stringify()`で1本の文字列に変換して保存しています。保存キーは`anti-vision-todo-state-v3`です
  ```js
  localStorage.setItem(STORAGE_KEY, JSON.stringify(state));
  ```
- **保存場所**: あなたのPC/スマホのディスク上に、ブラウザごとの形式(Chrome/EdgeはLevelDB、FirefoxはSQLiteなど)で実ファイルとして保存されます
- **単位**: ブラウザの「オリジン(プロトコル+ドメイン)」ごとに独立しています。他のサイトや、同じPCの別のブラウザからは見えません
- **端末をまたいだ同期はされません**。Chromeにログインして同期をオンにしていても、localStorageは同期対象に含まれていないため、別の端末を開くとデータは空の状態から始まります
- **キャッシュとは別物**です。「キャッシュを削除」では消えず、「Cookieとサイトデータを削除」のような操作で消えます

## データとプライバシー

すべてのデータ(アンチビジョンの本文、行動ログなど)はあなたのブラウザ内にのみ保存されます。外部サーバーには一切送信されません。ブラウザのサイトデータを削除すると、保存した記録も削除されるのでご注意ください。
